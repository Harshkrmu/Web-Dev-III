# Smart Utility Toolkit

A collection of Node.js core-module mini utilities built for Web Dev III (Unit 1).

## Files
- calculator.js  – CLI calculator using process.argv
- modules/isEven.js, modules/logger.js – custom reusable modules
- app.js – demonstrates module reuse
- server.js – HTTP server with routing
- fileManager.js – CRUD file operations using fs
- dice.js – random dice roller using crypto

## How to Run
node calculator.js add 10 5
node app.js
node server.js
node fileManager.js
node dice.js
